# Color Match Game

目標色を見ながらRGBを調整し、照合と再調整を繰り返して色彩感覚を学ぶブラウザゲームです。

## 遊び方

1. `TARGET` の色を観察します。
2. R・G・Bのバーを操作して `YOU` の色を作ります。
3. 「照合する」で、知覚的な色差と難易度に応じたヒントを確認します。
4. 同じ問題を調整し直し、CIEDE2000の色差 `ΔE00` が3以下になればクリアです。
5. 「答えを見る」で目標と自分のRGB値を振り返ります。

## 難易度

- **初級**: 明るさとRGBごとの調整方向・程度を表示します。
- **中級**: RGBごとの調整方向だけを表示します。
- **上級**: 知覚的な近さだけを表示し、現在のRGB値を隠します。

## 操作

- RGBバー上半分を押す: `+1`
- RGBバー下半分を押す: `-1`
- RGBバーを上下にスワイプ: 連続調整
- `ALL +10` / `ALL -10`: 全チャンネルをまとめて調整
- キーボード: `A/Z` がR、`S/X` がG、`D/C` がB、`Space` が照合
- フォーカス中のRGBバー: 矢印キーで微調整

## 色差の計算

画面上のsRGB値を次の順序で変換し、CIEDE2000で知覚的な色差を計算します。

```text
sRGB → 線形RGB → XYZ（D65）→ CIELAB → CIEDE2000
```

RGBごとのヒントは「どの操作をすべきか」を示すための符号付きRGB差、総合的な近さは「見た目がどれくらい違うか」を示すCIEDE2000として役割を分けています。

実装は `color-science.js`、参照値による検証は `tests/color-science.test.js` にあります。

```sh
node --test tests/color-science.test.js
```

## 保存データ

難易度、連続クリア数、直近5件の記録をブラウザの `localStorage` に保存します。遊び方画面から確認付きで記録をリセットできます。サーバーへの送信は行いません。
